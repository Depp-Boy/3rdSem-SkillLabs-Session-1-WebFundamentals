Client-Server Architecture & Network Tab Lab

When you open a webpage, your browser (Client) sends requests over the Internet to a Web Server, which returns the HTML, CSS, JavaScript, and Images.

The 7-Step Request-Response Cycle

  1. The browser generates a request when you type a URL or click a link.
  2. The request is sent to the web server over the Internet.
  3. The server processes the incoming request.
  4. The server may access a database to fetch or update data.
  5. The server generates a response (with a status code like 200 OK).
  6. The response is returned to the browser.
  7. The browser renders the received HTML, CSS, and images onto your screen.
