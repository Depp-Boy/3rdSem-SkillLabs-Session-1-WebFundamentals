Inspect Me with Developer Tools!

Browser Developer Tools allow you to inspect and debug HTML and CSS live in the browser without changing your actual source file.

Try these 3 quick experiments using Inspect (F12):

  1. Elements Tab (HTML): Right-click the red heading above, choose Inspect, double-click the text inside the <h1> tag, and change it to your own name!
  2. Styles Pane (CSS): In the Styles panel on the right, find .secret-heading and change color: #d9534f; to color: green;.
  3. Box Model Inspector: Scroll to the bottom of the Styles panel to see the rectangular Box Model diagram showing this card's exact content size, padding (25px), and border (3px).
