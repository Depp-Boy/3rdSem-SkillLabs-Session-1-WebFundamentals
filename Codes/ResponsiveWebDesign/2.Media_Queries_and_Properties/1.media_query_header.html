Mobile-First Media Query (@media (min-width: 768px))

Try resizing this browser window!

  • Below 768px (Mobile): The header uses flex-direction: column; so the title and navigation links stack vertically.
  • 768px and wider (Tablet/Desktop): The @media (min-width: 768px) rule activates and switches the header to flex-direction: row; with justify-content: space-between;!
